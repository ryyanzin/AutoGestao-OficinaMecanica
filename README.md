# 🔧 AutoGestao-OficinaMecanica

**📌 Sobre o Projeto**

O **Sistema AutoGestão de Oficina Mecânica** é uma aplicação desenvolvida para facilitar a organização e o gerenciamento das informações de uma oficina, permitindo o controle de clientes, veículos, funcionários e serviços realizados.

O objetivo é centralizar os dados em um único sistema, tornando os processos mais organizados, práticos e eficientes.

---

**⚙️ Funcionalidades Implementadas**
O sistema atualmente oferece as seguintes funcionalidades:

- **Cadastro de clientes:** registrar informações como nome, telefone e endereço.
- **Cadastro de veículos:** armazenar informações como modelo, marca, placa e proprietário.
- **Controle de serviços:** registrar os serviços realizados nos veículos, permitindo acompanhar os reparos.
- **Cadastro de funcionários:** registrar nome, telefone e função dos colaboradores da oficina.
- **Armazenamento em JSON:** salvar os dados de clientes, veículos e serviços em arquivos JSON, mantendo as informações disponíveis mesmo após fechar o sistema.
- **Edição de clientes:** permitir a atualização das informações dos clientes cadastrados.

---

**👤 Cadastro de Clientes**

A funcionalidade de cadastro de clientes permite:

- Informar o nome do cliente.
- Informar o telefone.
- Informar o endereço.
- Cadastrar os dados.
- Visualizar os clientes cadastrados em uma listagem.
- Editar as informações de clientes já cadastrados.

---

**🚗 Cadastro de Veículos**

A funcionalidade de cadastro de veículos permite:

- Informar o modelo do veículo.
- Informar a marca.
- Informar a placa.
- Identificar o proprietário.
- Cadastrar e visualizar os veículos registrados no sistema.

---

**🔧 Controle de Serviços**

A funcionalidade de controle de serviços permite:

- Registrar os serviços realizados nos veículos.
- Informar a descrição do serviço.
- Identificar o veículo atendido.
- Armazenar os registros para facilitar o acompanhamento dos reparos.

---

**👥 Cadastro de Funcionários**

A funcionalidade de cadastro de funcionários permite:

- Informar o nome do funcionário.
- Informar o telefone.
- Informar a função exercida na oficina.
- Cadastrar e visualizar os colaboradores registrados.

---

**💾 Armazenamento de Dados**

O sistema utiliza arquivos JSON para:

- Salvar os dados dos clientes.
- Salvar os dados dos veículos.
- Salvar os registros de serviços.
- Manter as informações disponíveis mesmo após o encerramento e a reabertura do sistema.

---

**🔮 Funcionalidades Futuras**

As próximas etapas de desenvolvimento incluem:

- **Edição de veículos:** permitir alterar as informações dos veículos cadastrados.
- **Cadastro de fornecedores:** registrar nome, contato e endereço dos fornecedores.
- **Registro de compras:** controlar as compras de peças, informando produto, quantidade, fornecedor e valor, além de registrar as entradas no estoque.
- **Controle de peças utilizadas:** registrar as peças utilizadas durante os serviços e atualizar as quantidades disponíveis no estoque.

---

**🚀 Objetivo do Sistema**

Facilitar a administração de uma oficina mecânica por meio da organização das informações de clientes, veículos, funcionários e serviços, contribuindo para um atendimento mais eficiente e um melhor controle dos processos internos.
