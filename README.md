# 🔧 AutoGestao-OficinaMecanica

📌 Sobre o Projeto:

O Sistema AutoGestão de Oficina Mecânica é uma aplicação desenvolvida para facilitar a organização e o gerenciamento das informações de uma oficina, permitindo o controle de clientes, veículos e serviços realizados. O objetivo é centralizar os dados em um único sistema, tornando os processos mais organizados, práticos e eficientes.
---
⚙️ Funcionalidades:

O sistema tem como objetivo oferecer as seguintes funcionalidades:

Cadastro de clientes: registrar informações dos clientes, como nome, telefone e endereço.
Cadastro de veículos: armazenar informações dos veículos, como modelo, marca, placa e proprietário.
Controle de serviços: registrar os serviços realizados nos veículos, facilitando o acompanhamento dos reparos.
---
👤 Cadastro de Clientes:

A funcionalidade de cadastro de clientes permite:

-Informar o nome do cliente.
-Informar o telefone.
-Informar o endereço.
-Cadastrar os dados.
-Visualizar os clientes cadastrados em uma listagem.
-Os campos obrigatórios devem ser preenchidos para que o cadastro seja realizado corretamente.
---
🚀 Objetivo do Sistema:

Facilitar a administração de uma oficina mecânica por meio da organização dos dados dos clientes, veículos e serviços, contribuindo para um atendimento mais eficiente e um melhor controle das informações.
---
🔮 Funcionalidades Futuras:

-Edição e exclusão de clientes.
-Pesquisa de clientes cadastrados.
-Cadastro e gerenciamento de veículos.
-Registro e acompanhamento de serviços.
-Integração com banco de dados.
-Histórico de serviços por veículo.
---
📄 Status do Projeto:

Em desenvolvimento.

Atualmente, o foco está na implementação do cadastro de clientes. As funcionalidades de cadastro de veículos e controle de serviços fazem parte dos objetivos futuros do sistema.
